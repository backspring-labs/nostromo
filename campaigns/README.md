# Campaigns

The outer loop's campaign plans: what Nostromo proposes to run on SquadOps, and why.

- **Here:** Nostromo's own campaign plans and reviews. Once the crew is commissioned, the definitions
  it runs live here too, approved by the owner's merge (Bootstrap Plan §8.14).
- **Not here:** the campaigns SquadOps runs to verify itself (shakeouts, diagnostics, pre-registered
  sets). Those live in squad-ops beside the project they evolve (squad-ops #1941).

The test is whether the campaign would still be run if Nostromo did not exist. If it would, it
belongs to SquadOps.
